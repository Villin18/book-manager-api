# Тест-план проекта Book Manager API

## 1. О проекте

| Параметр | Значение |
|----------|----------|
| Название | Book Manager API |
| Версия | 1.0.0 |
| Тип тестирования | API, функциональное |

---

## 2. Что тестируем

| Модуль | Что проверяем |
|--------|----------------|
| CRUD | Создание, чтение, обновление, удаление книг |
| API | GET, POST, PUT, DELETE запросы |
| Валидация | Правильность данных (Pydantic) |
| Поиск | Поиск по названию, автору, жанру |
| Статистика | Подсчёт книг, авторов |

---

## 3. Что НЕ тестируем

- Авторизация / логин
- UI (графический интерфейс)
- Нагрузка (1000+ запросов)

---

## 4. Виды тестов

| Тип | Инструмент |
|-----|------------|
| Модульные тесты | Pytest |
| API тесты | FastAPI TestClient |
| Интеграционные | Pytest + SQLite |

---

## 5. Тестовые данные

### Валидная книга
```json
{
  "title": "1984",
  "author": "George Orwell",
  "year": 1949,
  "genre": "Dystopian",
  "is_read": true
}
```
### Невалидная книга (нет названия)
```json
{
  "author": "Unknown"
}
```
