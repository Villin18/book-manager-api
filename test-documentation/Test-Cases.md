## TC-001: Создание книги с корректными данными

| Поле | Значение |
|------|----------|
| Название | Создание книги с валидными данными |
| Приоритет | Высокий |
| Тип | Позитивный |
| Автотест | test_create_book_success |

**Шаги:**
1. Отправить POST запрос на /books с валидным JSON
2. Проверить статус ответа

**Ожидаемый результат:** HTTP 201, книга создана

**Фактический результат:** HTTP 422 Unprocessable Entity

**Статус:** ❌ FAILED

**Причина:** Pydantic схема требует поле id, которое отсутствует при создании

**Тестовые данные:**

    {
      "title": "1984",
      "author": "George Orwell",
      "year": 1949,
      "genre": "Dystopian",
      "is_read": true
    }
