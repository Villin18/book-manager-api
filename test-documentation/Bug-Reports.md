# 🐛 Баг-репорты (по результатам автотестов)

## BUG-001: Невозможно создать книгу через API

| Поле | Значение |
|------|----------|
| ID | BUG-001 |
| Серьёзность | Critical (критический) |
| Приоритет | High (высокий) |
| Статус | Open |
| Обнаружил | Автотест test_create_book_success |

### Описание
При отправке POST запроса на /books с валидными данными API возвращает ошибку 422 Unprocessable Entity.

### Шаги воспроизведения
1. Отправить POST запрос на http://localhost:8000/books
2. Тело запроса:

        {
          "title": "1984",
          "author": "George Orwell",
          "year": 1949,
          "genre": "Dystopian",
          "is_read": true
        }

### Ожидаемый результат
HTTP 201 Created, книга создана

### Фактический результат
HTTP 422 Unprocessable Entity

Ответ сервера:

    {
      "detail": [
        {
          "type": "missing",
          "loc": ["body", "id"],
          "msg": "Field required",
          "input": {...}
        }
      ]
    }

### Причина
Pydantic схема Book требует обязательное поле id, но при создании книги id не передаётся (он генерируется БД автоматически).

### Затронутые тесты
- test_create_book_success (FAILED)
- test_get_all_books_with_data (ERROR)
- test_get_book_by_id (ERROR)
- test_delete_book (ERROR)
- test_search_books (FAILED)

### Окружение
- Python: 3.12.6
- FastAPI: 0.104.1
- Pydantic: 2.5.0

## BUG-002: Отсутствует валидация года издания

| Поле | Значение |
|------|----------|
| ID | BUG-002 |
| Серьёзность | Minor (незначительный) |
| Приоритет | Low (низкий) |
| Статус | Open |
| Обнаружил | Ручная проверка |

### Описание
API позволяет указать год издания в будущем (например, 2030) или отрицательные значения.

### Шаги воспроизведения
1. Отправить POST запрос с year = 2030

### Ожидаемый результат
Ошибка валидации (год не может быть больше текущего)

### Фактический результат
Книга успешно создаётся
